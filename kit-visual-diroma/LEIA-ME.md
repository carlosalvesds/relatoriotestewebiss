# Kit visual diRoma

Para usar: extraia este ZIP, coloque a pasta à disposição da ferramenta de desenvolvimento do outro projeto e envie o conteúdo de `PROMPT-PARA-OUTRO-PROJETO.txt`.

Conteúdo:
- `assets/diroma-logo.png`: logo original usada na aplicação.
- `GUIA-VISUAL.md`: cores, tipografia, componentes, enquadramento da logo e responsividade.
- `PROMPT-PARA-OUTRO-PROJETO.txt`: instruções prontas para aplicação em outro projeto.
- `tema/tokens.css` e `tema/tokens.json`: paletas clara e escura para adaptação a qualquer framework.
- `referencia/portal-original.css`: CSS original, sem alterações.
- `referencia/tema-escuro-original.css`: regras escuras extraídas de app.py.
- `referencia/streamlit-theme.toml`: somente a configuração visual de base do Streamlit.

O kit inclui apenas os recursos visuais e instruções. Não inclui dados de notas fiscais, ambiente Python nem código de negócio. O arquivo Logo_nfe.png não foi incluído porque não é a logo carregada pela aplicação atual.
